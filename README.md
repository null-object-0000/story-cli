# StoryPack

> **让每一本故事拥有一个会随着读者一起成长、绝不剧透、并以这个故事自己的方式呈现知识的智能百科与阅读伴侣。**

## 产品原则

### 1. 随阅读成长 · Progress-aware

系统展示的知识始终与读者当前阅读进度一致。

### 2. 永不剧透 · Spoiler-free

尚未读到的信息，对当前读者而言不存在。

### 3. 为记忆服务 · Memory-first

不是追求最完整的百科，而是帮助读者快速找回已经读过但忘记的信息。

### 4. 尊重故事自身 · Story-native

每个故事拥有自己的世界模型和最佳表达方式；系统适应故事，而不是要求故事适应固定模板。
